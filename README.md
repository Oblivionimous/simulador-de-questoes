# Simulador de Questões

Simulador de prova estilo VCE Player (HTML + CSS + JS, sem frameworks e sem
build), com banco de questões em arquivos `.txt` padronizados e carregamento
dinâmico opcional via PHP. Funciona 100% offline também, bastando abrir o
`index.html`.

O código do app fica em [`vce-web/`](vce-web/). A documentação completa —
funcionalidades, como o app funciona por dentro, como rodar e como adicionar
novos simulados — está em **[`vce-web/README.md`](vce-web/README.md)**.
