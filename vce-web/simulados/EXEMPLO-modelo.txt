@@@1
TOPICO: 1
TIPO: single
PERGUNTA: Qual comando exibe o nome do host atual do sistema Linux?
A: hostname
B: whoami
C: uname -a
D: id
RESPOSTA: A
EXPLICACAO: O comando hostname exibe (sem argumentos) o nome do host configurado no sistema.
Usado com um argumento, ele tambem pode definir um novo nome de host temporariamente (ate o proximo boot).
whoami mostra o usuario logado, uname -a mostra informacoes do kernel e id mostra UID/GID; nenhum retorna o hostname.

@@@2
TOPICO: 1
TIPO: multi
PERGUNTA: Quais comandos podem exibir informacoes de uso de memoria? (Escolha DUAS.)
A: free
B: vmstat
C: passwd
D: chmod
RESPOSTA: A,B
EXPLICACAO: free mostra um resumo de memoria RAM e swap: total, usada, livre, buffers e cache.
vmstat tambem reporta memoria, alem de estatisticas de paginacao (swap) e I/O em uma unica saida.
passwd gerencia senhas de usuarios e chmod altera permissoes de arquivos; nenhum dos dois exibe uso de memoria.

TOPICO: 2
TIPO: text
PERGUNTA: Informe o caminho completo do arquivo que define os pontos de montagem carregados no boot.
RESPOSTA: /etc/fstab
EXPLICACAO: O arquivo /etc/fstab lista os sistemas de arquivos que devem ser montados automaticamente durante o boot.
Cada linha define o dispositivo, o ponto de montagem, o tipo de filesystem, as opcoes de montagem, e os campos de dump e ordem do fsck.
E consultado tanto pelo processo de boot quanto pelo comando mount quando usado sem todos os parametros.
